# 称骨计算数据表

本文件为称骨算法与歌诀的完整数据参考，供解读时直接查阅。所有计算以 `scripts/chenggu_cli.py` 为准，本表用于解释与回答「某个骨重对应什么歌诀」这类问题。

## 一、算法规则

传统称骨（袁天罡称骨歌）把人的出生年月日时四项各自对应一个权重（单位「两」），四项相加即为「总骨重」，范围 2.1～7.1 两。

| 柱 | 取权重依据 | 说明 |
|----|-----------|------|
| 年柱 | 六十甲子（60 个，对应出生年干支） | 由公历年份换算干支 `((年-4)%60+60)%60` 取下标 |
| 月柱 | 农历月（1-12） | 正月到腊月各有一个权重 |
| 日柱 | 农历日（1-30） | 初一到三十各有一个权重 |
| 时柱 | 出生时辰（12 个） | 子时到亥时各有一个权重 |

计算为固定查表加总，非预测。歌诀一律为传统文化解读版，不做吉凶判定。
