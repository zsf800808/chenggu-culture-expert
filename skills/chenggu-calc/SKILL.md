# 称骨计算技能

本技能面向普通用户，用「查表计算」的方式完成传统称骨算法。工作方式是：

1. 先收集信息（公历年、农历月、农历日、时辰）。
2. 再用脚本做固定查表计算，不靠心算。
3. 最后用文化解读的口吻讲解歌诀，并附劝勉与免责声明。

不渲染吉凶、不预测命运，定位是传统文化与民俗知识。

## 触发范围

以下场景应使用本技能：

- 用户要算称骨（输入生日+时辰，得出几两几钱）。
- 用户要查某个骨重对应的传统歌诀。
- 用户想了解称骨歌、干支历法、农历月日时等民俗文化知识。

以下场景不要直接计算：

- 用户信息不全（缺年份/月份/日期/时辰）。
- 用户只是闲聊，没有明确要算。

## 总原则

- 固定计算一律调用 `scripts/chenggu_cli.py`。
- 不手算，不脑补。
- 歌诀一律用文化解读口吻，不做吉凶判定。
- 结尾附免责声明。

## 工作流

### 第 1 步：收集信息

正式计算前，需要四项信息：

1. 公历出生年份（如 1990）
2. 农历出生月份（1-12，如「三月」= 3）
3. 农历出生日期（1-30，如「初五」= 5）
4. 出生时辰（十二时辰之一：子/丑/寅/卯/辰/巳/午/未/申/酉/戌/亥时）

信息不全只追问，不硬算。时辰尤其要明确到十二时辰之一。

### 第 2 步：调用脚本计算

脚本路径以 skill 根目录为基准：

```bash
python "scripts/chenggu_cli.py" --year 1990 --month 3 --day 5 --hour 辰时
```

或传入 JSON：

```bash
python "scripts/chenggu_cli.py" --json '{"year":1990,"month":3,"day":5,"hour":"辰时"}'
```

### 第 3 步：读取脚本输出

重点读取：`ganzhi`（年干支）、`weights`（年/月/日/时四柱权重）、`total`（总骨重，单位两）、`total_text`（几两几钱）、`ge`（歌诀文化解读）、`level`（等级）。

### 第 4 步：解读与输出

统一按这个结构：

1. 已确认信息
2. 干支与四柱权重
3. 总骨重（几两几钱）
4. 歌诀文化解读
5. 劝勉建议
6. 免责声明

## 输出风格

- 面向普通用户，先说人话，再补术语。
- 不做吉凶判定，歌诀用文化解读口吻。
- 结论平和，不恐吓、不绝对化。
